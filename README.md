# Kafka OTUS

Курс по Apache Kafka на платформе OTUS: [https://otus.ru/lessons/kafka/](https://otus.ru/lessons/kafka/)

## Домашние задания

В этом репозитории будут размещаться все домашние задания курса. Каждое ДЗ нужно сдавать через merge request.

### Инструкция по сдаче ДЗ:

1. Создайте ветку от `develop` с названием `feature/hw<number>-<username>`
2. Выполните задание в соответствующей папке
3. Отправьте merge request в ветку `develop`
