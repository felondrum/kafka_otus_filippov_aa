### Phase 1: RocksDB State Store + DSL Hopping Window (Frequent Calls)

**Files to modify:**
- `FrequentCallsProcessor.java` — replace in-memory counter with DSL windowing

**Changes:**
1. Use `KStream.groupByKey()` + `.windowedBy(TimeWindows.ofSizeAndAdvance(60000, 10000))`
2. Use `.count(Materialized.as("frequent-calls-count"))` with RocksDB
3. Use `KStreamJoined.with(Serdes.String(), windowedValueSerde)` for state store
4. Process windowed results with `.toStream()` + `.filter()` for threshold
5. Write alerts with pattern="FREQUENT_CALLS" and count field
6. Kafka Streams manages RocksDB automatically (state.dir config already present)

**Key API (Kafka Streams 3.6.1):**
```java
KStream<String, String> windowed = callStream
    .filter((key, value) -> extractDuration(value) >= 5)  // short call filter
    .mapValues(value -> extractPhone(value))
    .groupBy((phone, phone) -> phone, Grouped.with(Serdes.String(), Serdes.String()))
    .windowedBy(TimeWindows.ofSizeAndAdvance(60000, 10000))
    .count(Materialized.as("frequent-calls-count"));

windowed.toStream()
    .filter((windowedKey, count) -> count > 5 && !windowedKey.window().isExpired(System.currentTimeMillis(), 60000))
    .map((windowedKey, count) -> KeyValue.pair(
        windowedKey.key(),
        createAvroAlert(windowedKey.key(), "FREQUENT_CALLS", count.intValue())))
    .mapValues(alert -> serializeAvro(alert))
    .to("calls.fraud-alerts", Produced.with(Serdes.String(), avroSerde));
```

### Phase 2: NPS Escalation with Processor API + State Store

**Files to modify:**
- `NpsEscalationProcessor.java` — replace in-memory map with Processor API

**Changes:**
1. Create custom `Processor<String, String>` implementation
2. Use `StateStore` (RocksDB) to track `(negativeCount, lastActivityTimestamp)` per phone
3. Implement `init()` to get state store reference
4. Implement `process()` to update counter and check threshold
5. Use `Context.forward()` to write alerts
6. TTL cleanup via `purgeExpired()` or periodic task

**Key API:**
```java
public class NpsEscalationProcessor<K, V> implements Processor<K, V> {
    private ProcessorContext<String, FraudAlert> context;
    private KeyValueStore<String, NpsState> store;
    
    @Override
    public void init(ProcessorContext ctx) {
        this.context = ctx;
        this.store = (KeyValueStore) ctx.getStateStore("nps-escalation-store");
    }
    
    @Override
    public void process(String phone, String value) {
        Integer npsScore = extractNpsScore(value);
        if (npsScore != null && npsScore < 2) {
            NpsState state = store.get(phone);
            if (state == null) {
                state = new NpsState(0, System.currentTimeMillis());
            }
            state.negativeCount++;
            state.lastActivity = System.currentTimeMillis();
            store.put(phone, state);
            
            if (state.negativeCount >= 3) {
                FraudAlert alert = createAlert(phone, "NPS_ESCALATION", state.negativeCount);
                context.forward("fraud-alerts", phone, alert);
                store.delete(phone);  // reset
            }
        }
    }
}
```
